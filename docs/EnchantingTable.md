# Enchanting Table Levels

Divine Enchantments uses a fixed enchanting table schedule for every enchantment that can come from the table. Treasure-only enchantments are excluded.

## How it works

- The enchanting table has a power level from 1 to 30.
- Each table enchantment has a first table level and a highest tier unlock.
- Table power below the first level cannot offer that enchantment.
- Higher table power unlocks higher tiers. The highest tier unlocks at level 30 or earlier.
- Table level 30 can offer every table enchantment at its highest available tier.
- Treasure enchantments never appear in the table.

## Quick bands

| Band | First table level | Examples |
| :-- | :-- | :-- |
| Common | 1 | Glimmer, Silt Sifter, Tempered Core |
| Early uncommon | 5 | Chainsaw, Demonic Edge, Hunter |
| Utility uncommon | 8 | Feathered Draw, Puncture, Scavenger's Habit |
| Rare | 10 | Breach, Bullseye, Machine Bow, Stagger |
| Very rare | 20 | Ally, Riches, Rune: Carnage |
| Pinnacle | 25-30 | Ballistic Overdrive, Grounded Vanguard, Gambler's Gambit, Muzzle, Slip-Bore |

## Notes

- The table range shows the first and last table power that can offer the enchantment.
- A higher tier replaces lower tiers at the same table power. For example, at level 30 a max-tier enchantment is offered at its top tier, not at tier I.
- The table UI caps at level 30. Item enchantability can push the internal roll slightly above the displayed level, so the listed levels are nominal table levels.
- Table power above 30 does not unlock new Divine Enchantments. Use an anvil to combine lower tiers if a modded table stops at a lower cap.
- Disabled enchantments are removed from the table pool by the config master switch and per-enchantment toggles.
